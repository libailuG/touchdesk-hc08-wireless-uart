TouchDesk 串口助手 v0.9.2-status

这是独立工程；TouchDeskOnDemand 和之前的工程保留。
在桌面向上滑动找到“串口助手”，也可在非应用状态通过诊断命令 app ui serial 打开。

操作
1. 发送页同时显示 data1~data10，点击字段打开数字键盘。
2. data1、data2 为十进制 uint32，范围 0~4294967295。
3. data3~data10 为 float32，支持负数、小数、科学计数。确认后更新待发送值。
4. 点击“发送一次”发送一帧；长按不会连续发送。启动或接收不会自动发送；状态开关每次切换立即发一帧。
5. 接收页显示最近一帧和 TX/RX 帧数，接收字段只读。切换页不改变待发送值。
6. 左上角 < 返回桌面。退出后释放 UART 驱动和会话内存，恢复串口诊断。
7. 本版字段值只保留到退出应用，不写入 NVS。

串口
开发板 TX GPIO43、RX GPIO44；921600、8N1、无流控。
电脑 COM10 是外部 PL2303GC，用于模拟下位机；COM 编号属于电脑端。
应用运行时独占此 UART，停止文本命令解析并屏蔽 ESP_LOG，避免污染二进制帧。
应用内请通过触屏返回；此时 app home 等文本命令不生效。

帧格式（发送/接收一致）
所有字段小端，共 48 字节，无 CRC、无额外长度或命令字段：
偏移  0: uint32 start_flag = 0xAAAAAAAA
偏移  4: uint32 data1
偏移  8: uint32 data2
偏移 12: float32 data3
偏移 16: float32 data4
偏移 20: float32 data5
偏移 24: float32 data6
偏移 28: float32 data7
偏移 32: float32 data8
偏移 36: float32 data9
偏移 40: float32 data10
偏移 44: uint32 end_flag = 0xEEEEEEEE
float32 使用 IEEE 754。不是 ASCII 字符串。标记允许出现在数据字段内部。
接收支持拆包、连续多帧以及丢弃噪声/错误帧尾后重新同步。
没有 CRC 时无法识别仍满足首尾标记的数据位错误。

PC 模拟器（安装 Python 和 pyserial）
先打开开发板串口助手，再运行：
python tools/serial_simulator.py --port COM10 --echo
在触屏点击发送，电脑打印收到的十项数据并原样返回，切到接收页查看。
也可让电脑先发一帧：
python tools/serial_simulator.py --port COM10 --values 1 2 -1.25 0 1.5 42 0.0001 1000 -2.5 3.25
默认只监听，不定时发送。Ctrl+C 退出并释放 COM10。

开发验证
tests/serial_protocol.py：协议编码、浮点位模式和碎片/噪声解析。
tests/serial_ui.py --output <目录>：实际 LVGL 渲染和触摸/编辑/生命周期验证。
tests/service_lifecycle.py：依赖服务按需初始化和退出释放。
显式诊断命令 serial test 用于测试：打开测试会话，2秒后依次点击两个状态开关，
12秒后自动退出并报告帧计数。只有此诊断入口会触发测试发送；桌面入口不会。

构建：PowerShell ./tools/build.ps1 -BuildDirectory build-serial
烧录只更新 ota0 应用区 0x20000；已有 resources 分区沿用当前匹配资源。
请勿将应用 bin 当成包含引导器/分区/资源的完整合并固件。

状态位更新
发送/接收页顶部四个控件，编号1~4分别对应data1的bit0~bit3。
发送页点击切换开/关，只改这一位，保留高28位；立即发送完整48字节帧。
长按不连发；滑出开关取消点击时不发送。编辑数值仍需点击“发送一次”。
编辑完整data1数值后自动更新四个状态，切换状态也同步data1数值。
接收页显示只读灯，绿色为1、灰色为0；问号代表尚未收到帧。
48字节结构不变，start_flag固定0xAAAAAAAA，end_flag固定0xEEEEEEEE。
显式serial test诊断会点击状态1、2，每次点击各发送一次，
其测试data1依次为0x12345679、0x1234567B，用于验证实际按钮回调和高28位保护。

横屏实时曲线更新
串口应用现在采用480x320横屏；发送/接收/曲线三个页签都按横屏布局。
退出应用恢复原桌面320x480竖屏，显示与触摸坐标一起旋转。
曲线页与确认效果图对应：左侧图形，右侧data3~data10选择、最新值、暂停、清空。
曲线默认data3、5秒窗口，可选择0.25、1、2、5、10秒。
X轴按开发板收到完整有效帧的单调时间绘制，右端0为最新接收时刻；停止接收后保留最后画面。
每帧的8个通道和接收时间保存在PSRAM的12000帧环形历史中，约563KiB。
1ms/帧时可覆盖完整10秒；超过缓存容量时，X轴说明末尾显示*表示历史不足。
绘图改为1000个等时间间隔位置，每个位置选择接收时间最近的原始样本；距离相同时取较早接收时间。
取样只依据时间，不依据数值大小，不插值；5秒窗口相邻位置约5.005ms。
时间范围内尚无历史覆盖的左侧位置留空；低速数据可能在多个位置选中同一原始样本。
选中的样本为NaN/Inf时显示断点。Y轴按选中有限样本自动缩放。
没有被等时间位置选中的窄尖峰可能不显示，原始接收历史仍完整保存。
PSRAM接收历史环512帧，UI按100ms取批次；超过512未读取的旧帧会被覆盖，
lost计数显示此类丢失，图上N显示当前时间窗口内的帧数。
接收时间由软件读取完整帧时记录，不是发送端采样时间；USB/串口批量到达会反映在时间坐标上。
暂停不停止收数，继续后显示所选时间范围内的最新历史；切换时间范围可重新查看历史。
清空历史不改变RX计数和发送参数。
非有限浮点值在曲线中显示为断点。缓存和曲线资源退出应用后释放。
控制台命令serial curve可直接进入曲线页，不自动发送。
联调：电脑Qt点击“开始持续发送 sin”，即可观察连续波形；默认关闭。

均匀时间采样固件：touchdesk-0.9.2-uniform-1000.bin；保留已验证的横屏内部DMA缓冲修复。
新PSRAM历史仅在进入串口应用时分配，退出释放；散点图X/Y资源显式释放。
算法验证：tests/serial_plot_test.c；真实LVGL五档切换/300次退出进入：tests/serial_ui.py。

主题混用修复：touchdesk-0.9.2-theme-fix.bin。
三套主题统一应用于原生控件、下拉列表/选中项、曲线/网格、编辑键盘和滑条。
切换页面清除容器旧样式，重新应用当前主题，避免旧背景与新控件混用。
曲线使用当前主题强调色；金色主题强调按钮采用深色字保证对比度。
原协议、1ms发送测试、1000个均匀时间绘图位置和100ms刷新周期保持。
验证：tests/theme_ui.py，THEME_FIX_VALIDATION.txt。

返回桌面布局修复：touchdesk-0.9.2-return-fix.bin。
ui_reset_page只重设配色与字体，不再删除容器的全部样式；保留x/y/width/height。
原因：LVGL将位置和尺寸也保存在本地样式内，删除全部样式会破坏桌面(0,36,320,444)布局。
新增旧代码失败/修复后通过的桌面几何检查，以及串口左上角返回后的竖屏重绘检查。
